# Baseline profile for the app's own code: ahead-of-time compilation for
# everything under our packages, the way the Compose and Media3 libraries
# already ship theirs. Without it our code starts every install interpreted
# and JIT-compiled piece by piece, which is the first-launch and first-scroll
# jank a release build still had.
#
# Wildcards rather than a recorded profile: recording one needs a macrobenchmark
# run on an API 33+ or rooted device. This is a superset of any recorded journey
# for our own code; the libraries' own profiles cover theirs.
#
# The packages below are the app's other code that runs before the first frame and during the first scroll: the shared UI (the new
# look's theme, shell, palette, bottom chrome and every page), the design tokens, the cover palette, the look settings and the mode
# host. They were not listed, so they ran interpreted on every install until the runtime had seen them often enough to compile
# them, which is a slow cold start that a wildcard on com/cosmotune/music alone never reached.
