## How this sheet was filled

The "In the code" column was filled from the source at commit 286ef2a8 by searching and reading the code, not by running the apps. `present` means the whole row is in the code on every platform where it makes sense; `partly` means only some of the row's parts, or only one of the two apps where both make sense; `absent` lists the search terms tried. The Result column is for what a person sees: rows 1 to 12 are empty until someone tries them on the phone or the desktop app, and rows 13 to 15 come from the desktop run log and the code. Rows marked `partly` or `absent` in the code column are the first candidates for the roadmap.
