# Upstream implementation checklist — 28 October 2026

This is the implementation follow-up to the [20-repository review](UPSTREAM_REVIEW_2026-10-28.md). The current published app is **1.0.10**. Source changes below require a new installer; a documentation update does not update an installed app. Validation is recorded separately from source implementation and device/operator checks.

## Recording matching and Gilli playback

- JioSaavn uses one recording matcher on Android and desktop: title, album/film, runtime, version and explicit edition. Artist credits provide supporting evidence; an exact album/title and close runtime can identify a recording despite completely different credits. No new performer alias table is used.
- Search begins with the title and album, followed by title alone and a credited-person query. Missing album/runtime can be filled from the exact played YouTube ID with a bounded lookup and short-lived cache, without changing the listener's displayed credit.
- Small title-spelling differences or shortened titles need an exact album and runtime within two seconds. Competing near-title recordings, incompatible versions and ambiguous album performances are refused. An unrelated singer plus the same runtime alone is insufficient.
- JioSaavn's featured/singer/composer metadata is retained instead of discarding everything except its primary byline. Actor/lyricist-only auxiliary credits do not establish a performer match.
- The private audit covers **137 distinct song/artist entries** from retained history and older playback logs, excluding 22 retained radio stations. Of 89 non-video music entries, **88 have compatible catalogue matches**. Seven newly recovered entries passed the actual production adapter and native AAC decoder: Rangola, Achcho/Achacho, Atu Itu Ooguthu, Cheppamma, Manmadha, Naa Manasuney and Netho Cheppana. The one remaining Aaduvari entry was not present in the inspected five-track JioSaavn Kushi edition and keeps its native fallback. Forty-eight video-upload entries retain original video audio; diagnostic catalogue matches do not authorize replacing that audio. Personal history/raw responses stay in ignored `build/jiosaavn-history-audit/`, not Git.
- Desktop Gilli videos were found and aligned but rejected after a wrapper restored the original `(From "Gilli")` title. The handoff now preserves the shared provider's clean metadata. Real decoder checks produced frames for Appadipodu, Kokkorakko and Arjunar Villu. Short clips/unmapped intervals still use the cover; this does not claim continuous video coverage.
- Signed-video URLs now expire in the engine session, backend format cache and Android/desktop artwork caches. Measured timing maps can be reused while obtaining a fresh stream.

## Remaining integration requirements

This pass does not close hardware/account checks, real party/Komga/Subsonic deployments, publisher/operator failures, or every feature that was deliberately deferred. In particular:

- Browser Automix's live-song transition listening and native helper/browser-package validation remain separate from the passing synthetic analysis/render tests.
- Podio archive/download/completion and TV/browser interfaces are implemented. Watch Podio and physical listening/OS-chooser checks remain separate.
- Manga verification/cookie handoff, collections/backups, optional library update checks, TAR-family imports and common-control translations are implemented. RAR/7z/PDF, technical-text translation and real extension/device compatibility remain limited. [Completed lifecycle/cache work](MANGA_UPSTREAM_REPAIR_2026-10-28.md).
- Provider supported finite HLS/DASH preparation and typed PCM/verified-lossless FLAC conversion are implemented. Unsupported manifest layouts, arbitrary processing hooks, per-operator availability and actual immersive output remain limited.
- Opt-in desktop exclusive/hog-mode/direct output and original fullscreen visuals are implemented; physical macOS/Linux/DAC validation remains. Native DSD/DoP and bidirectional file synchronization remain unimplemented; third-party Workshop scenes are not redistributed.
- Existing 1.0.10 installers do not contain this source pass. No version tag should move to make a source-only change look released.

Final validation and publication evidence will be added when the source pass is complete. The recommendation model remains 3.19 MB and was not retrained by this work. Dataset-refresh scheduling remains deferred as requested.
