# Cosmotune 1.0.25

This update fixes Windows installs and updates, keeps Up next going when your YouTube sign-in runs out, and moves the sign-in
notice out of the way.

## Highlights

- <!-- icon: download --> **Install anywhere** — Any folder on Windows, Program Files too.
- <!-- icon: check --> **Updates reopen** — Windows asks once, then Cosmotune reopens.
- <!-- icon: playback --> **Up next keeps going** — Autoplay works after your sign-in runs out.
- <!-- icon: settings --> **Tidier sign-in notice** — It sits under the top bar, not over pages.

## Windows

- Cosmotune now installs for all users. The installer asks where to install, Program Files included, and adds a Start menu entry
  and a desktop shortcut. 1.0.23 and 1.0.24 installed for the current user only, so choosing Program Files there failed with
  "insufficient privileges".
- Update now installs into the folder Cosmotune is in, after Windows' permission prompt, and opens Cosmotune again. Saying No to
  the prompt keeps the version you have and opens it again.
- The first update from 1.0.23 or 1.0.24 removes the copy installed for the current user only and installs for all users into the
  same folder, behind the same single prompt.
- Each update writes what it did, step by step, to `.local\state\cosmotune\updates\update-steps.log` in your user folder.
  More in the [desktop guide](../../DESKTOP.md).

## Music

- When your YouTube sign-in runs out while Cosmotune is open, Up next, autoplay and Home carry on as a guest, as they already did
  when Cosmotune started with an expired sign-in. Signing in again brings your account back.
- The "sign-in has expired" notice sits under the top bar on desktop, on a solid background, so it no longer covers the page or
  Now Playing.
- The log now records which sign-in cookies YouTube set or cleared, by name only (never their values), and whether YouTube
  still saw you as signed in, to find why a sign-in ends early.

## Before you update

If Cosmotune 1.0.23 or 1.0.24 on your computer did not open again after an update, open it from the Start menu once and choose
Update now; or download the 1.0.25 installer from this page. Windows will ask for permission once.
