# Cosmotune 1.0.11

This release improves recording matching, music-video discovery, audio diagnostics, podcasts, Manga and the browser companion.

## Playback and discovery

- JioSaavn compares the song, film/album, duration and recording version instead of requiring identical singer/composer credits. Seven recovered history recordings were tested through the production adapter and native AAC decoder; unavailable catalogue entries retain the original source.
- OpenCanvas handles descriptive title subtitles and short numeric film names, and can corroborate an unbadged publisher through reciprocal links from a verified publisher channel. Weak encoded-frame alignment tries the other stream encoding without lowering confidence or discarding still-artwork evidence. Idhazhin Oram and Aadungada Enna Suthi passed automatic discovery, measured alignment and native video decoding.
- Video handoff preserves the measured recording identity; expired media addresses are refreshed while retaining timing maps. Unmatched sections continue to show the cover.
- Provider comparison preserves completed offers and applies useful desktop upgrades without waiting for stalled sources. Verification requirements and provider errors remain actionable.
- The quality badge has room at larger text sizes. Audio details distinguish the active decoder from offers, estimated tiers and derived PCM throughput; stale Android telemetry cannot overwrite the current song.
- Desktop adds opt-in WASAPI exclusive, CoreAudio and ALSA direct-output paths with safe fallback and honest precision reporting, original fullscreen visuals, and secondary-click song actions. Physical DAC precision and macOS/Linux direct-output execution still require device validation.

## Podio and library tools

- Public YouTube Music podcasts, publisher RSS/Atom archive pagination, OPML import/export, played/resume progress, background sleep controls and finite episode downloads/offline playback are integrated. Public feeds require no listener account; protected and paid-only audio is not unlocked.
- TV has a remote-friendly Podio page; the browser companion has radio/podcast browsing and persistent controls with music/Podio playback exclusion. Watch Podio remains for a later release.
- Playlist import previews UTF-8 M3U/M3U8, CSV and song links, preserves ordering and lets users exclude entries before saving. Listening statistics add daily and hourly activity views.

## Manga

- Collections, filters, portable metadata backup preview/merge, optional daily/weekly library update checks, and CBT/TAR/TAR.GZ/TGZ import are available. Update scheduling defaults to off and does not download chapters automatically.
- Isolated website-verification flows retain short-lived origin-scoped cookie/user-agent handoff. Cache expiry, duplicate requests, source removal and extension replacement are repaired.
- Common Manga controls are translated into ten Indian languages. Technical text falls back to English; RAR/7z/PDF still require conversion.

## Providers and browser companion

- Finite supported HLS/DASH media is fetched through package-scoped transport and prepared locally. SDK media tools support stream copy, PCM16/24 WAV and verified-lossless FLAC conversion. Live/changing manifests, unsupported layouts, arbitrary encoder hooks and key/license acquisition remain explicit errors.
- Browser Automix includes local analysis, AutoDJ, dual-deck transitions and playback controls. Optional analysis models download on first use and are integrity checked; they are separate from the unchanged 3.19 MB recommendation ranker.
- Local party-server tests and portable builds pass; this release does not deploy a public party server.

## Release limits

Bidirectional file synchronization, Watch Podio and native DSD/DoP are not included. Platform builds, automated tests and public-media probes do not replace physical phone/watch/TV, DAC, Cast, provider-account or macOS/Linux listening checks. Third-party catalogue and gateway availability varies. See [remaining work](../PENDING_WORK.md) and [upstream integration evidence](../UPSTREAM_IMPLEMENTATION_2026-10-28.md).
