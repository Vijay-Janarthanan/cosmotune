## Now Playing

- On portrait phones, the artwork view shows a compact pill for the current decoder format when there’s room. Tap it to open Audio Pipeline.
- Seek by tapping or dragging near the artwork ring. A gesture that starts across the artwork leaves playback position alone.
- Music-video matching checks for reprises and singer-specific editions and rejects game edits. Animated covers are checked again when the album credit arrives.

## Playback and providers

- Desktop AutoMix recovers from stalled decoders during handoff and falls back to simpler transitions if failures repeat.
- Desktop covers share a bounded image cache. Decorative artwork loops use less decoding memory while synchronized music videos keep their normal playback settings.
- Android and desktop prefer synced FLAC lyrics and preserve vocal labels, timing and independently timed backing vocals.
- Provider registries filter incompatible runtimes. Supported provider packages can use a custom download URL with permission limited to that server. Amazon Music 2.3.19 is available through the provider package update screen.

## Watch, Podio and Books

- **Watch → Live TV → All channels** shows the full catalogue. Free-TV/IPTV is enabled by default. Back returns to the guide after switching between channels.
- **Podio → Following** lets you limit recent episodes per show and apply skip-silence settings across selected subscriptions.
- **Books → Browse → New Classics** offers free EPUB editions from Standard Ebooks alongside Project Gutenberg, Open Library and connected libraries.
