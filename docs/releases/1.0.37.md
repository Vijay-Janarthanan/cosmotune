# Cosmotune 1.0.37

Live TV keeps its free channels when a channel list drops for a moment, and says so when a source doesn't answer.

## Highlights

- <!-- icon: tv --> **Channels stay listed** — A dropped download no longer hides them.
- <!-- icon: playback --> **Try again for sources** — See which source failed and ask it again.

## Watch

- When the connection dropped partway through one of iptv-org's channel lists, Live TV and search left out every iptv-org
  channel for half an hour. The list is now downloaded once more, and if that fails too the copy from last time is used.
- A channel list that a source failed to answer is kept for two minutes instead of thirty, so the next search asks that
  source again.
- Live TV names a source that didn't answer, with Try again. On the Plugins page a failing source says why in plain words and
  has its own Try again button; the message goes away by itself once the source answers.
