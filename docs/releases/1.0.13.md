# Cosmotune 1.0.13

This release repairs a crash when returning from picture-in-picture, a Quit that could leave the process running during an install, an empty Up next, and Video's sign-in at launch, and it adds frame smoothing on Android.

## Fixes

- Returning from the desktop picture-in-picture window could crash the application: the smoothing code drew a video frame that the decoder thread had just freed. Drawing now holds the same lock as the decoder, closed frames are skipped, and the window is released only after the page has taken the picture back. New tests exercise twenty open/return cycles and drawing racing a release.
- Picture-in-picture controls hide about a quarter of a second after the pointer leaves the window (also over another application) and stay while you drag or resize. While a video is in picture-in-picture, the main window's panel now carries the player settings, the live Stats for nerds card, captions, queue, seek and play controls and Return; the picture-in-picture window itself shows only the video and its hover controls.
- Quit from the tray ends the process by force after four seconds when the orderly shutdown stalls, and a Windows request to close the application (an installer replacing its files, or a shutdown) is answered by quitting instead of being swallowed by the tray. A setup left running by an earlier hung install is not cleared by this release: restart Windows once.
- Up next asks YouTube's own suggestions when the video source returns none, keeps a failed lookup from being remembered, and shows a loading state, the list, or a "Try again" note. Autoplay and Next use the filled list.
- On a phone, the launch screen dissolves into the first frame, the audio cache opens off the main thread and the startup packages are in the baseline profile. Video's sign-in no longer waits for Music to be opened first. These were changed without a device to time them on.
- Frame smoothing reads the refresh rate of the monitor the video window is on, not the primary one, and maps 59/143/119 to 60/144/120.

## Android smoothing

- Blend and Smooth are available on Android phones and tablets, marked Experimental and off by default, up to the screen's refresh rate (a faster display mode is requested above 60 fps) with the audio delayed to match. Phones that support only the older graphics level get Blend. Off, 30 fps and above (with the toggle on) and HDR keep the normal player, and any graphics or shader error returns to it with a notice. The graphics path has not run on a phone or emulator; the shaders were run only on a desktop software renderer.

## Release limits

Watch Podio, bidirectional file synchronization and native DSD/DoP are not included. The signed-in YouTube features, picture-in-picture, the local player and Android smoothing were built and tested without a physical device or Google account. See [the 1.0.12 notes](../releases/1.0.12.md).
