# Cosmotune 1.0.8

## Native UI and artwork

- Manga and Podio use shared mode headers and tab navigation with Music's fonts and artwork palette. Manga has Library/Discover navigation, clearer source/import controls and rounded covers with a persistent fallback.
- Material secondary/tertiary controls now follow the artwork palette instead of retaining stock purple colours, in both light and dark themes.
- Artist headers keep their original photograph mounted underneath Apple artwork. Delayed, missing or expired Apple images no longer clear a working banner. Motion artwork retains the same still underneath.

## Radio

- Normalize directory language filters to lowercase: `Tamil` previously returned no results on the tested mirror, while `tamil` returned hundreds.
- Request up to 1,000 stations for filtered browsing, show the result count and active region, and provide Clear to remove combined filters. A US + Tamil filter can legitimately have far fewer results than worldwide Tamil.
- Add an expanded radio map, a larger inline phone map, larger station markers and zoom up to 8×. Stations without coordinates remain available in the list.
- Keep directory results visible when switching between radio and podcasts after closing the map.

## Homepage discovery

- Replace exhaustive ISO menus with India/Global/US/UK and common Indian languages plus English.
- Put the selected language, regional charts and supported provider feeds ahead of the ordinary Home shelves. Language results no longer wait for a slower chart request. Refresh discards stale discovery shelves.
- Preserve valid regional chart playlist cards that YouTube now places under “Video charts”; the ordinary Home parser's unrelated video exclusions remain in place.
- These controls change discovery shelves and supported provider feeds; account-personalized recommendations remain available below them. They do not change the interface language or verify a recording's language.

## Verification

Regression checks cover lowercase radio requests, the larger result limit, chart playlist parsing, discovery ordering, palette roles, late/failed artist-image replacement, Manga navigation and radio filtering/map expansion. Native phone/desktop fixture screens are rendered for visual review. Live catalogue probes returned distinct 20-song lists for Tamil, Hindi and English and different India/global chart shelves.

Public radio availability and publisher metadata can change. Podcast downloads/OPML and additional regional podcast adapters remain pending; this release does not add access to paid-only audio. Dedicated Podio interfaces for TV, Wear and browser remain outside this release.
