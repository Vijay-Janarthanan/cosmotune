# Cosmotune 1.0.26

This update keeps your YouTube sign-in on the desktop, and makes installing and updating on Windows dependable: the installer
closes a running Cosmotune itself, and updates download even when one of GitHub's servers cannot be reached.

## Highlights

- <!-- icon: download --> **Updates always download** — Any of GitHub's servers will do now.
- <!-- icon: check --> **Install while it's open** — The installer closes Cosmotune for you.
- <!-- icon: settings --> **No restart needed** — Files are replaced at once, nothing later.
- <!-- icon: playback --> **Sign-in that stays** — YouTube no longer signs you out.

## Windows

- Update now downloads through every address GitHub lists for its download server, a few seconds each. Before, it tried only
  the first one, so on a network that could not reach that one address every try failed with "Connect timeout has expired".
- Installing Cosmotune while it is open now closes it first: Cosmotune is asked to close and quits properly, and the installer
  then replaces its files. Before, the installer could not close it, asked for a restart, and the restart deleted most of the
  new version's files, so Cosmotune would not start until it was repaired.
- A download that cannot reach the server now says so in a sentence, without the server's long address.
- More in the [desktop guide](../../DESKTOP.md).

## Music

- Signing in to YouTube Music on the desktop now keeps you signed in. The sign-in window used to read your sign-in while the
  YouTube Music page was still running, and that page renews it by itself: a renewal after the reading left Cosmotune a copy
  YouTube had moved past, and YouTube then ended the whole session, minutes after you signed in. The sign-in is now read from a
  page that runs nothing, and Cosmotune no longer renews it again in the same second (YouTube answered that with "too many
  requests"). If you were signed out, sign in once more after updating.

## Before you update

If you installed 1.0.25 while Cosmotune was open and Windows asked to restart, run the 1.0.25 or 1.0.26 installer once after your
next restart and choose Repair, or install 1.0.26 over it. On a network where Update now in 1.0.25 or earlier stops with "Connect
timeout has expired", download the 1.0.26 installer from this page once; from 1.0.26 on, Update now works there.
