# Cosmotune 1.0.23

**Before you update:** if Cosmotune 1.0.21 or 1.0.22 on your computer closes with an error when it starts, download 1.0.23 from this
page and install it over the top. You only need to do this once. From 1.0.23 on, Cosmotune updates itself.

## Highlights

- <!-- icon: download --> **Update in one click** — It downloads, installs and opens again.
- <!-- icon: new --> **Never miss an update** — Checked while it runs, in every mode.
- <!-- icon: settings --> **Choose where to install** — Windows asks for a folder and adds a shortcut.
- <!-- icon: tv --> **Fewer steps on Android** — Phone and TV updates install with less tapping.
- <!-- icon: check --> **Opens every time** — No more crash when an update is out.

## Updating

- **Windows and Mac:** Update now downloads the new version inside Cosmotune with its progress, then Cosmotune closes, installs it
  and opens again by itself. Nothing to do in the tray, the installer or Finder.
- **Later:** a put-off update stays in the top bar as an Update button, in Music, Video, Watch and every other mode.
- **Checked while running:** Cosmotune looks for a new version every few hours and when you bring its window back from the tray,
  not only when it starts.
- **If something goes wrong:** a failed download or install leaves your current version working, and Cosmotune says what happened
  with Try again and the download page.
- **Phone and TV:** updates install through Android's own installer. From Android 12, once Cosmotune has updated itself once, later
  updates need no "Install?" tap. After an update, a notification opens Cosmotune again.

## Installing

- **Windows:** the installer asks where to install (your own user folder is suggested) and adds a desktop shortcut and a Start
  menu entry.
- **Mac:** open the disk image and drag Cosmotune to Applications. The `.pkg` installer is no longer made.

## Fixes

- **Launch crash:** the desktop no longer closes with "CosmoLookTheme is not installed" when a newer version is out. The update card
  and What's new now work wherever they open, on the desktop and the TV.

## Release limits

- **Old versions:** 1.0.21 and 1.0.22 cannot use the new updates; install 1.0.23 by hand once (see the top of these notes).
- **Unsigned:** Cosmotune is not signed by Microsoft or Apple. The first install still shows SmartScreen on Windows and needs
  right-click > Open on a Mac; updates done by Cosmotune itself do not.
- **Mac from the disk image:** a Cosmotune run straight from the disk image updates through the download page; move it to
  Applications for one-click updates. A Mac that installed the old `.pkg` asks for its password once, on the next update.
- **Portable zip and Linux:** they update through the download page, as before.
- **Not yet tried on real devices:** the Mac update, and Android's update without the "Install?" tap.
