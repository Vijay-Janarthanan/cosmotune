# Cosmotune 1.0.2

- Better music-video discovery uses film/album metadata, title variants and independent publisher evidence. Matching song audio alone no longer qualifies a personal dance upload.
- Local subject framing follows faces and people, resets at cuts/seeks and keeps the full frame visible for groups or uncertain scenes. A short wide-composition hold reduces fit/crop flicker.
- Android and desktop use the same upstream OpenCanvas camera policy and viewport geometry. Android detector models and licences are packaged explicitly and checked by SHA-256 in each APK.
- Includes the 1.0.1 desktop tooltip-crash, duplicate-instance and tray/startup fixes. Failed Windows media-control startup now also cleans up its native thread instead of aborting on exit.

The player layout is unchanged. Decorative videos remain silent; song audio continues from the existing music source.

Both reported Godavari songs were checked against their original song audio. Core/app unit suites, actual desktop film-frame diagnostics and all four local Android APK model/resource checks passed before release packaging. The Release workflow runs platform tests/builds before publishing.

Physical Android texture/GPU behavior, battery and thermal cost remain unmeasured. Model failures fall back to the full video frame. See the [OpenCanvas validation report](https://github.com/Vijay-Janarthanan/OpenCanvas/blob/main/docs/VALIDATION_2026-10-23.md).

The app version is 1.0.2. Android's upgrade code advances to 6; the Windows numeric installer build advances to 1.0.4 to preserve upgrade ordering from earlier installers.
