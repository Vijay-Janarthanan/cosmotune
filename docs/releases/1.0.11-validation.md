## Initial CI failure and repair

The initial tagged run failed the release-notes link contract on desktop jobs and two native PCM/FLAC conversion tests on macOS. A same-folder notes link was outside the release body's supported relative-link rewrite; it now uses the supported docs-relative path. The local test task now declares release notes, README and both workflow files as inputs, preventing a previously passing cached result from hiding later documentation changes.

Both codec drain loops now use FFmpeg's native `AVERROR_EAGAIN()` instead of hardcoding `-11`, which is not portable to macOS. The exact release contract/version and real native media-conversion suites pass locally after this repair. The replacement tagged CI run provides the macOS execution and cross-platform packaging result.
