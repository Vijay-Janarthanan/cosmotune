# Cosmotune 1.0.1

- Fixed the desktop tooltip crash when hovering or pressing icon buttons by aligning the shared UI's Material API with the packaged desktop runtime.
- Reopening Cosmotune now restores the existing desktop window instead of starting another player and tray icon. The startup guard applies to Windows, Linux and macOS.
- A single left click on the Windows/AWT tray icon restores the window. Quit removes the icon before exiting.
- Android and desktop report version 1.0.1. Android build code is 5; the desktop installer version is 1.0.3 so it upgrades the previous 1.0.2 installer correctly.

Validation: shared, shared UI, video, desktop, Compose interaction and Android unit suites completed with 4,718 passing tests and nine skips. The tooltip interaction tests reproduce the original missing-method crash before the fix and pass afterwards. Windows packaging succeeded; final interactive launch/install verification remains outstanding.
