# Browser catalogue parser fixtures

Anonymous catalogue responses imported from the pinned upstream repository named in `../UPSTREAM_IMPORT.json`. Original fixture files and source SHA256 values are recorded there. They contain no signed-in account capture and are used only by parser tests; Vite does not copy this folder into the site.

Captured lyric documents, Spotify captures and capture tooling were excluded from this port. Browser lyric tests use short inline timing fixtures. A successful parser test does not prove that the current service, account authorization or media endpoint is available.
