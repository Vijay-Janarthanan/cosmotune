# Podio resources

`land.json` contains rounded 1:110m land outlines from Natural Earth, fetched from
`nvkelso/natural-earth-vector/geojson/ne_110m_land.geojson` on 26 October 2026.
Natural Earth map data are in the public domain:
https://www.naturalearthdata.com/about/terms-of-use/

`Votify-LICENSE.txt` is the full MIT permission notice for the Votify source used
as reference for anonymous Spotify podcast metadata lookup. Audio comes from matched publisher RSS. No Python
runtime, downloader, account-cookie importer, Widevine or music decryption code
is bundled with Podio.
