`golden.json` is the designer's reference output (`ui/v3/dynamic-colour-v3.js`, run unchanged) for 61 seeds in both themes. It holds the v2 colours (v3 only adds fields: every v2 value is byte-identical to what `ui/v2/dynamic-colour.js` gave) and the v3 colours: `glass` (with its alpha), `skelBase`, `skelShine`, `danger`, `onDanger`, `dangerContainer`, `onDangerContainer` and the flag `dangerClash` (`rim`, for the dropped family A, is not kept). Rerun when the designer changes the formulas: `node make-golden.mjs "<path to ui/v3/dynamic-colour-v3.js>" > golden.json` from this folder (Node 18 or newer, no packages); `CoverPaletteGoldenTest` then shows what the Kotlin engine must follow.
